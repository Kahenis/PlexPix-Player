# Plex-Pix Player

Visionneuse **photos et vidéos Plex** android avec fonctions avancées,  compatible avec **tous les formats de smartphones** : écrans fins, formats classiques, paysage et **smartphones pliants** (détection automatique de la largeur) et du pliage/dépliage pour les smartphones concernés.

"Plex-Pix player" est le player photo/vidéo dédié a  Plex-Photos que l'on attendait depuis longtemps. Il ajoute de nombreux avantages comparés aux quelques fonctions purement basiques de l'application native de plex-photo. 

Il s'adapte donc parfaitement au principe de l'ensemble des applications proposées par Kahenis (Plex-pix pour android TV, Plex-Thumb pour Windows et Plex-pix Player pour Android classique) : Proposé aux utilisateurs de catégories "photo", tous les outils nécessaires pour une exploitation pleine et entière d'un photothèque de qualité.

- Bouton **Mise à jour** : vérifie le dépôt public et propose l’installation si une version plus récente existe.

### Fonctions
- Liaison à un vrai serveur Plex (`plex.tv/link` ou jeton local)
- Grille de miniatures avec cache local par dossier
- Lecture photo / vidéo (direct, remux, transcode)
- Zoom pincement deux doigts (sans changer de photo)
- Jauges de chargement dossier et fichier
- Classement par date (puis nom de fichier)
- Ascenseur de dates dans la grille
- Taille des miniatures réglable (très compact → très grand)
- Adaptation automatique portrait / paysage / pliant
