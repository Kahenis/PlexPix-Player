# Plex-Pix Player

Visionneuse **photos et vidéos Plex** avancée pour smartphone Android.

Compatible avec **tous les formats de smartphones** : écrans fins, formats classiques, paysage et **smartphones pliants** (détection automatique de la largeur).

### Fonctions
- Liaison à un vrai serveur Plex (`plex.tv/link` ou jeton local)
- Grille de miniatures avec cache local par dossier
- Lecture photo / vidéo (direct, remux, transcode)
- Zoom pincement deux doigts (sans changer de photo)
- Jauges de chargement dossier et fichier
- Classement par date (puis nom de fichier)
- Ascenseur de dates dans la grille
- Taille des miniatures réglable (très compact → très grand)
- Adaptation automatique portrait / paysage / pliant
