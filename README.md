# Plex-Pix Player

Visionneuse **photos et vidéos Plex** avancée pour smartphone Android (portrait, paysage, pliant).

## Version actuelle : 1.3.4

APK : voir les [Releases](https://github.com/Kahenis/PlexPix-Player/releases).

### 1.3.4
- Lecteur vidéo : lecture / pause / stop et **ligne de temps** (jauge de position), placés hors de la pellicule.
- Plein écran vidéo : un appui sur les commandes ne quitte plus le plein écran ; un tap sur l’image affiche ou masque la barre. Sortie par le bouton fenêtré ou le retour Android.
- Numéro de version affiché dans les paramètres.
- Bouton **Mise à jour** : vérifie le dépôt public et propose l’installation si une version plus récente existe.
- Easter egg *Chambre noire* (5 appuis sur le logo / la version au démarrage, ou 7 appuis sur le numéro dans les paramètres).

### Fonctions
- Liaison à un vrai serveur Plex (`plex.tv/link` ou jeton local)
- Grille de miniatures avec cache local par dossier
- Lecture photo / vidéo (direct, remux, transcode)
- Zoom pincement deux doigts (sans changer de photo)
- Jauges de chargement dossier et fichier
- Classement par date (puis nom de fichier)
- Ascenseur de dates dans la grille
- Taille des miniatures réglable (très compact → très grand)
- Adaptation automatique portrait / paysage / pliant
